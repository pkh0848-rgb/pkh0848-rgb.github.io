# ourLog

가족·친구와 함께 쓰는 기록 앱 모음의 시작 페이지입니다.
`https://pkh0848-rgb.github.io/`

Google 로그인 한 번으로 아래 서비스를 모두 이용할 수 있도록 만든 개인 프로젝트입니다.

| 앱 | 설명 |
|---|---|
| [somedayLog](https://pkh0848-rgb.github.io/somedaylog/) | 언젠가 하고 싶은 것을 담아두는 서랍 |
| [studyLog](https://pkh0848-rgb.github.io/study-calendar/) | 친구들과 함께 공부 목표 체크 |
| [healthLog](https://pkh0848-rgb.github.io/health-log/) | 운동·인바디 기록 |
| [우리집 플래너](https://pkh0848-rgb.github.io/home-planner/) | 집안일 나눠 맡기 |

- [개인정보처리방침](https://pkh0848-rgb.github.io/privacy.html)
- [이용약관](https://pkh0848-rgb.github.io/terms.html)

## 기술 스택

- HTML / CSS / JavaScript
- Firebase (Authentication, Firestore)
- GitHub Pages 배포, TWA 기반 Play Store 배포 준비

## 만든 이유

생활 기록용 앱을 여러 개 따로 만들다 보니 로그인과 진입 경로가 흩어지는 게 아쉬웠습니다. 하나의 런처 아래로 모아 가족·친구와 가볍게 기록을 나눠 쓸 수 있도록 만들었습니다.

이 저장소는 사이트 루트(`/`)를 담당하며, 앱을 하나로 묶는 런처 역할을 합니다.
Play Store에 TWA로 올릴 때 이 주소가 시작점이 됩니다.
